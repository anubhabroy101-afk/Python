# Python Class README Automation

When the user asks to "update this file" (referring to README.md in this folder):

## Instructions for the Agent

1. **Scan the folder**: List all `.py` files in `Python/class/` and their modification dates.

2. **Auto-detect staged files**: Files modified in the last 24 hours are automatically considered "staged".

3. **Identify recent files**: Files modified in the last 7 days go in the "Recent Updates" section, sorted by modification date (newest first).

4. **Identify completed files**: Files with the 🟢 emoji in the "Assignment Files" section are marked as completed.

5. **Update README.md** with this structure:
   - **Recent Updates**: List files modified recently (include modification date in format: `[filename.py](filename.py) — Updated: Mon, Jun 2`)
   - **📋 Staged Files**: User-specified files
   - **📝 Assignment Files**: Complete alphabetical list with 🟢 emoji for completed ones
   - **🎯 Topics Covered**: Keep as-is
   - **Last Updated**: Today's date

## Format for Recent Updates

Use format: `- [filename.py](filename.py) — Updated: Day, Mon Date`

## Automation Scope

- Only for README.md in the Python/class folder
- Auto-detect staged files (modified in last 24 hours)
- Auto-detect recent files by modification date
- Preserve emoji status in Assignment Files section
- No user interaction required

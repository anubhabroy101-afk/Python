## Detailed File Documentation

### 1. sum.py
**Description:** Finds the sum of two numbers provided by the user.
**Example:**
- Input: `5` and `3`
- Output: `The sum of 5 and 3 is 8`

### 2. area_triangle.py
**Description:** Calculates the area of a triangle using Heron's formula given three sides.
**Example:**
- Input: `a = 5`, `b = 6`, `c = 7`
- Output: `Area of the triangle is: 14.696938456699069`

### 3. greater.py
**Description:** Finds and prints the greatest among three given numbers.
**Example:**
- Input: `10`, `20`, `15`
- Output: `The greater number is: 20`

### 4. swap.py
**Description:** Swaps two numbers and displays before and after swap.
**Example:**
- Input: `a = 5`, `b = 10`
- Output: `Before swapping: a = 5 b = 10` and `After swapping: a = 10 b = 5`

### 5. factorial.py
**Description:** Calculates the factorial of a given number using a loop.
**Example:**
- Input: `5`
- Output: `The factorial of 5 is 120`

### 6. summation_N.py
**Description:** Finds the sum of first N natural numbers.
**Example:**
- Input: `5`
- Output: `Sum of first 5 natural numbers is: 15`

### 7. sum_in_digit.py
**Description:** Calculates the sum of all digits in a given number.
**Example:**
- Input: `12345`
- Output: `Sum of digits: 15`

### 8. fibonacci.py
**Description:** Generates and prints the Fibonacci series up to N terms.
**Example:**
- Input: `7`
- Output: `0 1 1 2 3 5 8`

### 9. odd_even.py
**Description:** Checks whether a given number is odd or even.
**Example:**
- Input: `10`
- Output: `The number is even.`

### 10. prime.py
**Description:** Checks if a number is prime or not using two different methods.
**Example:**
- Input: `17`
- Output: `17 is a prime number`

### 11. prime_in_range.py
**Description:** Finds and displays all prime numbers within a given range.
**Example:**
- Input: `10` and `25`
- Output: `Prime numbers between 10 and 25 are: 11, 13, 17, 19, 23`

### 12. prime_in_digit.py
**Description:** Extracts and displays all prime digits from a given number.
**Example:**
- Input: `1234567`
- Output: `Prime digits in 1234567 are: [2, 3, 5, 7]`

### 13. armstrong.py
**Description:** Checks if a number is an Armstrong number (sum of cubes of digits equals the number).
**Example:**
- Input: `153`
- Output: `153 is an Armstrong number`

### 14. palindrom.py
**Description:** Checks if a given number is a palindrome by reversing and comparing.
**Example:**
- Input: `12321`
- Output: `12321 is a palindrome`

### 15. quadratic1.py
**Description:** Solves quadratic equations and handles all cases (distinct, equal, and complex roots).
**Example:**
- Input: `a = 1`, `b = 5`, `c = 6`
- Output: `Two distinct real roots: Roots are: -2.0 -3.0`

### 16. quadratic2.py
**Description:** Solves quadratic equations using a function-based approach.
**Example:**
- Input: `1`, `-5`, `6`
- Output: `Two real roots: 3.0, 2.0`

### 17. pattern_1.py
**Description:** Prints a triangular pattern of asterisks using two different methods.
**Example:**
- Input: `5`
- Output:
```
*
* *
* * *
* * * *
* * * * *
```

### 18. pattern_2.py
**Description:** Prints a right-aligned triangular pattern of asterisks.
**Example:**
- Input: `5`
- Output:
```
    *
   * *
  * * *
 * * * *
* * * * *
```
